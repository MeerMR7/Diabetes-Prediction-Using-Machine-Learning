# Diabetes Prediction System

**Author:** Mir MUHAMMAD  
**Course:** Machine Learning

## Overview
Machine learning project to predict diabetes based on medical attributes using synthetically generated data.

## Dataset Features
- Glucose
- BloodPressure
- BMI
- Age
- Insulin
- Outcome (Target: 0 = No Diabetes, 1 = Diabetes)

## Models Compared
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 94% |
| Decision Tree | 100% |
| Random Forest | 100% |
| SVM | 96% |
| KNN | 93% |

## Key Findings
- **Best Models:** Decision Tree & Random Forest (100% accuracy)
- **Most Important Features:** Glucose, BMI, Age
